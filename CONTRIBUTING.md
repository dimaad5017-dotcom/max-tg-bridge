# Как помочь проекту

Проект открытый, и любая помощь принимается — в том числе от тех, кто не
программирует.

**Не работает?** Заведи
[issue](https://github.com/dimaad5017-dotcom/max-tg-bridge/issues/new/choose) по
шаблону «Что-то не работает». Самое ценное там — полный текст ошибки из чёрного
окна: по нему обычно всё понятно сразу.

**Только не выкладывай в issue токен бота, свой номер телефона и содержимое
`.env`.** Issue видят все. Если они попали в текст ошибки — замени
звёздочками. Токен, который засветился, надо сразу отзывать через @BotFather.

**Нашёл ошибку в инструкции?** Место, где ты застрял и полез гуглить, — это баг
README, а не твой. Расскажи, где именно застрял, это правда помогает.

**Хочешь поправить код?** Форк → ветка → pull request. Перед отправкой прогони
то же, что проверяет CI:

```bash
pip install ruff
ruff check bridge
ruff format --check bridge
```

Пара просьб по стилю: комментарии и сообщения пользователю — по-русски и
человеческим языком; комментарий объясняет **почему** так сделано, а не что
делает строка; мост не должен молча терять сообщения — если что-то не доехало,
он обязан об этом написать в тему.
