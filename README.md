# max-tg-bridge

Мост между MAX и Telegram для личного использования. Программа заходит в твой
аккаунт MAX как ещё одно устройство и перекладывает переписку в Telegram:
каждый чат MAX становится отдельной темой в твоей супергруппе. Отвечаешь в теме —
ответ уходит собеседнику в MAX. Приложение MAX при этом не нужно ни на телефоне,
ни на компьютере.

## Что нужно подготовить один раз

**1. Бот в Telegram.** Напиши [@BotFather](https://t.me/BotFather), команда
`/newbot`. Он выдаст токен вида `1234567890:AAE...` — это пароль от бота.

**2. Отключи боту режим приватности.** Там же у @BotFather: `/setprivacy` →
выбери своего бота → **Disable**. Без этого бот по умолчанию видит в группах
только команды, а обычный текст — нет, и ответы из тем не будут уходить в MAX.
Сделай это **до** добавления бота в группу: если бот уже в группе, после смены
настройки его нужно удалить из неё и добавить заново.

**3. Супергруппа с темами.** Создай в Telegram новую группу (можно одному),
зайди в настройки группы и включи **«Темы»** (Topics). Группа сама станет
супергруппой.

**4. Бот — админ группы.** Добавь своего бота в эту группу и выдай ему права
администратора. Обязательно нужны **«Управление темами»** и
**«Отправка сообщений»**.

**5. ID группы.** Напиши в группу любое сообщение, потом открой в браузере:

```
https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
```

Найди в ответе `"chat":{"id":-1001234567890`. Это и есть ID, он отрицательный.

## Установка

```powershell
cd max-tg-bridge
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Настройка

Двойной клик по **`1-настройки.cmd`** — откроется блокнот с файлом `.env`.
Заполни токен бота и ID группы, сохрани и закрой. Номер телефона вписывать не
обязательно: если строка пустая, его спросят при первом входе и сохранят сюда же.

## Вход в MAX

Двойной клик по **`2-вход-в-MAX.cmd`** (или `python login.py` из консоли).

Скрипт спросит номер, если он ещё не сохранён, и запросит SMS-код на него. Введи его — сессия сохранится в
`cache/max.db`, и больше SMS не понадобятся. В конце скрипт напечатает список
чатов, которые видит аккаунт: так ты сразу поймёшь, что вход прошёл.

Если на аккаунте включена двухфакторная защита, скрипт дополнительно спросит
пароль.

## Запуск моста

Двойной клик по **`3-запустить-мост.cmd`** (или `python -m bridge.main`).

Пока окно открыто — сообщения из MAX приходят в Telegram. Закроешь окно —
поток прекратится, но ничего не потеряется: сообщения полежат на сервере MAX и
подтянутся при следующем запуске.

## Как пользоваться

- **Новый чат в MAX** → бот сам создаёт под него тему в группе.
- **Ответить** → просто пиши в нужной теме.
- **Вступить в чат по ссылке-приглашению** → отправь боту в группе
  `/join ссылка`. Это удобно, когда друг скидывает приглашение в школьный чат:
  пересылаешь ссылку сюда и не открываешь MAX.

## Чего пока нет

Пересылаются только тексты. Вложения помечаются в теме как `[фото]`, `[файл]`,
`[голосовое]`, но сами файлы не передаются — это следующий шаг. Звонков и
видеозвонков не будет вообще.

## Безопасность

`.env` и папка `cache/` добавлены в `.gitignore` — не убирай их оттуда.
Файл `cache/max.db` это **действующий ключ от твоего аккаунта MAX**: кто его
скопирует, тот войдёт без SMS. Не выкладывай его никуда и не носи на флешке.

Отозвать доступ можно в любой момент из настроек MAX — раздел «Устройства»,
там эта сессия видна как отдельное устройство.

## Важно понимать

Библиотека `maxapi-python` использует внутренний, неофициальный API MAX. Это
нарушает условия сервиса, и аккаунт теоретически могут заблокировать. Также MAX
может сломать совместимость любым своим обновлением — тогда мост перестанет
работать до обновления библиотеки. Сквозного шифрования в MAX нет независимо от
того, пользуешься ты мостом или официальным приложением.
